# Bản dịch nguyên tử — toàn bộ project (VI)

Mục đích: tách mọi câu trong 4 tài liệu thành đơn vị nghĩa nhỏ nhất, dịch sang tiếng Việt đơn giản để bạn kiểm tra.
Quy ước: mỗi dòng `EN → VI`; ⚠ = đề mơ hồ, cần bạn xác nhận (đối chiếu mục 12 của BA doc).

## A. HeritageTrail-website.doc — đề bài chức năng (30 câu)

### A1. Name and Work

- `HeritageTrail website needs to be developed` → phải xây dựng website tên HeritageTrail
- `which will provide information about` → cung cấp thông tin về
- `various historical places` → nhiều nơi có tính lịch sử
- `heritage sites` → khu di sản
- `monuments` → tượng đài / công trình kỷ niệm
- `cultural landmarks` → công trình văn hoá nổi bật (làm mốc)
- `These heritage sites will provide information about their history` → mỗi site cho biết lịch sử
- `importance` → tầm quan trọng
- `architecture` → kiến trúc
- `cultural background` → nền tảng văn hoá
- `must flash the details` → phải hiển thị nổi bật chi tiết ⚠ "flash" không định nghĩa
- `all the activities or the events` → mọi hoạt động/sự kiện
- `going to happen` → sắp diễn ra
- `or conducted` → hoặc đã được tổ chức
- `allow adding new heritage site` → cho phép thêm site di sản mới
- `established to provide users a single platform` → thành lập để cho user 1 nền tảng duy nhất
- `to explore and learn about heritage places` → khám phá + học về nơi di sản

### A2. Website Requirement

- `designed with the aim to provide users with information` → thiết kế để cung cấp thông tin cho user
- `about historical and cultural heritage` → về di sản lịch sử & văn hoá
- `Various different types of heritage places and information` → nhiều loại nơi di sản + thông tin
- `provided for their benefit` → cung cấp vì lợi ích người xem
- `home page must have these menus like` → trang chủ có các menu
- `Home, Heritage Sites, Explore, About us, Events, Gallery, REGISTER` → 7 menu, đúng thứ tự này
- `look of the page must be designed with no blank space left` → thiết kế không để khoảng trống
- `designing section will work with two modules` → có 2 module
- `ADMIN` → quản trị
- `USER` → người dùng
- `Admin module will manage all other content` → admin quản lý toàn bộ nội dung khác
- `like editing heritage sites, about us, events, contact us, gallery and so on` → sửa sites, about us, events, contact us, gallery, "và các mục khác" ⚠ danh sách mở
- `User can see and navigate the content` → user xem + điều hướng nội dung

- `select the desired heritage site to view its details` → chọn site để xem chi tiết

- `Navigation must be user friendly and uniform` → điều hướng thân thiện + đồng nhất

- `must be listed with images` → phải liệt kê kèm ảnh
- `(can be more précised)` → (có thể chi tiết hơn tuỳ ý) ⚠
- `About us: various sub links and for each link a page must be designed` → About us có nhiều sub link, mỗi link 1 trang
- `whose information part can be edited by the admin member` → phần thông tin do admin sửa được
